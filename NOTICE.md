- What: `tools/webview2/Microsoft.Web.WebView2.Core.dll`,
  `Microsoft.Web.WebView2.WinForms.dll`, `WebView2Loader.dll`
  (plus `Microsoft.Web.WebView2.Core.xml`, the IntelliSense doc).
- Version: **1.0.4258.31**, taken unmodified from the NuGet package
  `Microsoft.Web.WebView2` (<https://www.nuget.org/packages/Microsoft.Web.WebView2/>).
- License: Microsoft's BSD-3-Clause style license, bundled in the package as
  `LICENSE.txt` — copied here as
  `THIRD_PARTY_LICENSES/Microsoft.Web.WebView2-BSD-3-Clause.txt`. It permits
  redistribution of source and binary forms with the copyright notice and
  disclaimer preserved; the full third-party notices file from the package is
  kept as `THIRD_PARTY_LICENSES/Microsoft.Web.WebView2-NOTICE.txt`.
- Role: compile-time reference for `tools/PlanoraServer.cs`, and runtime
  dependency shipped next to `Planora.exe` in the release zip.
- These DLLs are **binaries we did not build**. They are unmodified copies of
  Microsoft's published SDK output. To rebuild the exe against your own copy:
  `dotnet add package Microsoft.Web.WebView2` (or download the `.nupkg`, rename
  it to `.zip`, and take `lib/net462/*.dll` + `runtimes/win-x64/native/WebView2Loader.dll`).

> The **WebView2 Runtime** (the Edge/Chromium engine that renders the window) is a
> separate system component, usually preinstalled on Windows 10/11. It is not in
> this repository and stays under Microsoft's own terms.
